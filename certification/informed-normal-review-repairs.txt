Review repairs for feature/informed_priors
=========================================

Scope
-----
Responds to bgms_informed_priors_review_61342de.txt and its chat summary.
The original implementation report describes historical evidence; this report
records the subsequent repairs and additional checks. Neither report is a
uniform accuracy guarantee over all accepted prior matrices.

Repairs
-------
1. The conjugate edge move evaluates the integrated Gaussian mass directly,
   with log1p, before adding graph-prior odds and normalizer differences.
   It no longer subtracts the two large Gaussian log ordinates at zero.
   The same stable calculation covers the conditional Cauchy mixture;
   Gamma-diagonal corrections and reciprocal death probabilities remain.
2. All production normalizer solves disable Armadillo's approximate fallback.
   Unresolved solves and nonfinite draws propagate as normalizer failures.
   The extreme heterogeneous row/star reproductions must either agree with
   their independent anchors or fail explicitly; they cannot silently drop
   a Gaussian direction and cache a successful potential.
3. The independent R and C++ references calculate the candidate-edge Schur
   ratio directly. They do not subtract two completed-square log masses.
   Their numerical failures and invalid masses produce an inconclusive
   reference, not a resolved zero-error answer. The reference code does not
   call the production integrated-mass helper.
4. Context-aware alignment is shared by fitting, prior sampling, and reference
   evaluation. Data/graph names take precedence; absent graph names, prior
   sampling uses mean names, then SD names, then positional order. Unnamed
   matrices preserve their positional meaning. This is documented in the
   sample_ggm_prior help page.

Fast regressions
----------------
- Positive-quadrature comparisons for the integrated mass, mixed signs,
  nonzero natural means, ordinary SDs and SDs down to 2^-36.
- The review's ill-conditioned diagonal row and full three-node star.
- Narrow-SD reference checks against isolated-edge quadrature and an
  independently coded R candidate-mass expression.
- All four named/unnamed prior combinations, independently reordered named
  matrices, identical reference output under equivalent storage orders,
  and prior sampling with an unnamed mean but named SD matrix.
- 192 constrained finite-difference gradient checks: all 64 four-node graphs
  with heterogeneous signed means/SDs and three diagonal shapes.
- Actual public-fit failure and actual C++ parallel-runner fatal status.
  A real successful result and real fatal result are supplied together to
  the R dispatcher (only dispatch is mocked) to verify whole-fit rejection.

Standalone validation
---------------------
Run R from the project root. Install first with R CMD INSTALL . (no preclean).
Use OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 when running these scripts.

  Rscript tests/validation/informed-normal-narrow.R
  Rscript tests/validation/informed-normal-prior.R
  Rscript tests/validation/informed-normal-posterior.R
  Rscript tests/validation/informed-normal-graph-law.R
  Rscript tests/validation/informed-normal-heldout.R
  Rscript tests/validation/informed-normal-stress.R
  Rscript tests/validation/informed-normal-enumeration.R

The held-out script checks all 12 neighboring pairs at p=3 and all 192 at p=4,
including cycles and complete graphs. It separately checks graph-law TV,
heterogeneous star anchors at p=3/5/10/20, and path-to-cycle ratios at p=5/10/20.
The stress script uses stronger signed means and disparate SDs on stars in
both vertex orders and on a triangle. These scripts retain the ratio gate
(error + reference allowance <= .003 nat), reference half-width <= .0005,
and graph-law TV upper bound <= .005. The enumeration script compares the
sampled complete p=3 posterior graph law and PIPs with independent references.
Reference intervals are nominal batch-means intervals with the displayed
comparison adjustment. SMC's internal half-width alone is not certification.

Limitations and exploratory failures
------------------------------------
A p=3 posterior enumeration with inclusion probability .5, very narrow
near-zero priors, and 4 x 200000 retained iterations did not resolve the joint
graph law: TV estimate .006887, upper bound .027183. PIP point estimates were
close to their references. Nearly deterministic edge flips mix graph patterns
slowly in this configuration. It is not counted as a pass. The default
posterior enumeration uses probability .3; reproduce the .5 configuration by
setting BGMS_ENUM_PROB=0.5. BGMS_ENUM_ITER controls retained draws per chain.
This diagnostic does not establish a normalizer bias, and it does not justify
weakening the graph-law gate.

Large dense graphs and strong incompatible cycles at p=10/20 still lack a
broad independent certification bank. Large-p checks here concern explicitly
listed sparse configurations, not arbitrary priors or graphs. Extreme scale
heterogeneity may now produce an intentional whole-fit numerical failure.
The hierarchical prior continues to divide the within-graph density by Z(G);
Z(G) is not absorbed into the Bernoulli graph prior.
